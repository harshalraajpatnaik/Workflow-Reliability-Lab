# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within Workflow Reliability Lab, please send an email to the repository owner at `harshalraajpatnaik@ugmail.com`.

Please include:
- A description of the issue and potential impact.
- Steps to reproduce or proof-of-concept payload.
- Any relevant logs or configuration snippets.

We kindly ask that you give the project maintainers a reasonable amount of time to remediate the vulnerability before public disclosure.
